## 一、核心知识体系

### 1. ERP（企业资源规划）
由 Gartner Group 于 1990 年提出，是 **MRP II（Manufacturing Resource Planning II，制造资源计划 II）** 的下一代系统。

**核心定义**：对企业**三大流**进行全面集成管理的管理信息系统。
| 三大流 | 内容 |
|--------|------|
| 物流 | 原材料采购 → 加工制造 → 产品销售 |
| 资金流 | 资金流出（采购付款）→ 资金流入（销售收款） |
| **信息流** | **贯穿全程**的信息传递和反馈（协调驱动物流和资金流的"神经系统"） |

> ERP **不仅是信息系统，更是管理理论和管理思想**。

**ERP vs MRP II**（关键区分）：
| 维度 | MRP II | ERP |
|------|--------|-----|
| 核心 | 物流 | **财务**（所有业务的最终量化结果，统一度量衡监控全企业） |
| 范围 | 企业内部制造业 | **多行业供应链**（企业 + 供应商 + 客户） |
| 行业 | 传统制造业 | 零售、金融、能源等多行业 |

**ERP 11 个基本模块**：
| 类别 | 模块 | 缩写 |
|------|------|------|
| 计划类（5 层计划 + 执行层，层层细化） | 1. 生产预测 | — |
| | 2. 销售管理（计划） | — |
| | 3. 经营计划 / 生产计划大纲 | PP（Production Planning） |
| | 4. 主生产计划 | MPS（Master Production Schedule） |
| | 5. **物料需求计划**（生产管理**核心/枢纽**） | MRP（Material Requirements Planning） |
| | 6. 能力需求计划 | CRP（Capacity Requirements Planning） |
| | 7. 车间作业计划（JIT 模式） | PAC（Production Activity Control） |
| 管理类 | 8. 采购与库存管理 | — |
| | 9. 质量与设备管理（TQM） | — |
| | 10. **财务管理**（ERP 核心重心） | — |
| 扩展 | 11. ERP 扩展应用模块（CRM / DRP / SCM / EC） | — |

> 计划层次关系：预测 → 销售管理 → 经营计划 → 主生产计划 → 物料需求计划 → 车间作业，**上层管方向、下层管执行**。
> **MRP 是枢纽**：把上层计划翻译成可执行的零部件制造/采购计划，是从计划到实操的转折点。

**第 11 模块扩展应用**：CRM（Customer Relationship Management，客户关系管理）/ DRP（Distribution Resource Planning，分销资源管理）/ SCM（Supply Chain Management，供应链管理）/ EC（Electronic Commerce，电子商务）。本身也是独立系统，常作为独立软件出售。

**ERP 的 3 大功能**：
- 支持决策：实时分析，多工厂/多地点跨国经营
- 行业针对性：打破制造业局限，覆盖多行业
- **供应链扩展**：企业内部 → 全行业 → **跨行业供应链**（需多家企业都用 ERP + 统一数据标准和接口才能互通）

### 2. 电子政务（E-Government）
利用信息技术将政府管理和服务职能集成，在网络上实现政府组织结构和工作流程优化重组，超越时间、空间与部门分隔。

**3 个组成部分**：政府内部电子化/网络化办公（OA/MIS）+ 部门间信息共享与实时通信 + 政府与居民双向信息交流。

**5 大互动领域**（围绕政府 G / 企业 B / 居民 C 三个主体）：
| 简称 | 含义 | 方向 | 例子 |
|------|------|------|------|
| **G2G** | 政府 → 政府 | 上下级/同级 | 公文传递、内部 MIS、决策支持 |
| **G2B** | 政府 → 企业 | 政府→企业 | 发布政策法规、颁发营业执照/许可证 |
| **G2C** | 政府 → 居民 | 政府→居民 | 交管平台查违章、政务平台查社保、证件管理 |
| **B2G** | 企业 → 政府 | 企业→政府 | 企业报税、投标、供应商品 |
| **C2G** | 居民 → 政府 | 居民→政府 | 个人报税、参政议政、投诉建议、报警 |

> **快速判断**：左发起方、右接收方（如 G2C = 政府发起、居民接收）。**判断的是行为主体之间的互动方向，不看数据对象**。

**4 个发展阶段**（判断关键：有没有在网络上完成**整个业务闭环**）：
| 阶段 | 特点 | 例子 |
|------|------|------|
| 起步阶段 | 政府信息网上发布（静态） | 发布法规、机构、联系方式 |
| 单向互动 | 政府向用户提供服务 | 在线下载表格 |
| 双向互动 | 在线双向交互 | 在线填表并提交报税表 |
| **网上事务处理** | 以电子方式完成**完整业务闭环** | 在线报税 + 退税直接到账 |

> 注意：判断依据**不是"传了几轮信息"**，而是是否完成全流程闭环。数百个业务流不可能同时成熟，需分批开发，建设成熟可能需十几年甚至几十年。

**6 大应用领域**：面向社会 / 部门之间 / 部门内部 / 核心数据 / **政府电子化采购**（"政府的电子商务"）/ 电子社区。

### 3. 企业信息化
企业利用现代信息技术实现生产自动化、管理网络化、决策智能化、商务电子化的过程。
**核心和本质**：信息技术进行**知识的挖掘和编码** + 对**业务流程进行管理**。
**根本目的**：**提高企业竞争能力**。

**4 个创新层面**：技术创新（CAD/互联网）| 管理创新（财务→供应链/CRM/EC）| 制度创新（管理体制+监管体系）| 业务融合（IT 与业务流程融合）。

**3 个规划层面**：企业战略层面（业务策略/未来方向）→ 业务运作层面（关键业务流程，直接创造价值）→ 管理运作层面（辅助流程的 IT 支撑）。
> **战略数据模型**分两类：数据库模型（日常事务处理）+ 数据仓库模型（高层决策支持）。

**6 种企业信息化方法**：
| 方法 | 核心思想 | 性质 |
|------|---------|------|
| 业务流程重构 | 用 IT 对组织结构和工作方法**彻底重新设计** | **激进**（推翻重建，风险大） |
| 核心业务应用 | 围绕核心业务应用 IT | — |
| **信息系统建设** | 最具**普遍意义**（渐进，最多人用，非"最好"） | 渐进 |
| 主题数据库 | 面向核心业务主题，**避免信息孤岛** | — |
| 资源管理 | ERP / SCM 等工具应用 | — |
| 人力资本**投资** | 把优秀员工看作资本投资，适用智力密集型企业 | — |

> 易混点："最具普遍意义"≠ 最好的方法，而是**最多人用的方法**。

### 4. 全章贯穿主题：从分散到集成
| 出处 | 体现 |
|------|------|
| 诺兰模型 | 蔓延（分散）→ 控制 → 集成 |
| MIS | 公用数据/公用程序避免信息孤岛 |
| ERP | 从企业内部集成 → 跨行业供应链集成 |
| 主题数据库 | 面向核心业务主题，避免信息孤岛 |

## 二、顾问指引（真实项目里 AI 怎么用这些知识）

- 用户做企业信息化规划：先用 3 个规划层面（战略/业务/管理）梳理，再用 6 种方法选型（激进变革选业务流程重构，渐进稳妥选信息系统建设）。
- 用户做 ERP 选型/集成：先看 11 模块覆盖度，重点关注 MRP（枢纽）和财务（核心）；提醒跨企业集成需统一数据标准 + 接口协议。
- 用户做政务系统：用 5 大领域判断互动方向（左发起右接收），用 4 阶段判断成熟度（是否业务闭环）。
- 用户问"数据为什么对不上/系统为什么不通"：关联"信息孤岛"——可能没做主题数据库、没统一数据标准、各子系统没共享公用数据。
- 用户区分 ERP 与 MRP II：用"核心（物流 vs 财务）+ 范围（内部 vs 供应链）"两个维度讲。
- 用户做电商/供应链系统：关联 ERP 扩展模块（CRM/DRP/SCM/EC），说明这些常作为独立系统但需与 ERP 集成。

## 三、常见误区（AI 自检红线）

- ❌ **电子政务 5 领域用"数据对象"判断** → 应看**行为主体互动方向**（左发起、右接收）。例：人口信息采集是政府对政府（G2G），不是政府对居民。
- ❌ **电子政务 4 阶段用"传几轮信息"判断** → 应看**是否完成全流程业务闭环**。例：个税 APP 退税到账是第 4 阶段（网上事务处理），不是双向互动。
- ❌ **把 G2E（政府对公务员）当 5 大领域之一** → 5 大领域是 G2G / G2B / G2C / B2G / C2G，**不含 G2E**。
- ❌ **说主题数据库"形成信息孤岛"** → 说反了，主题数据库是**为了避免**信息孤岛。
- ❌ **把"人力资本投资"说成"人力资源管理"** → 偷换概念，方法名是"人力资本**投资**"。
- ❌ **把 SCM 当业务流程重构的手段** → SCM 是**资源管理**方法，不是业务流程重构手段。
- ❌ **说"信息系统建设是最具普遍意义 = 最好"** → 是**最多人用**，不是最好。
- ❌ **把 MRP II 和 MRP 混为一谈** → MRP II 是制造资源计划 II（企业级），MRP 是物料需求计划（ERP 的一个模块，生产管理枢纽）。
- ❌ **说 ERP 核心是物流** → ERP 核心是**财务**（物流是 MRP II 的核心）。
