## 一、核心知识体系

### 1. 密钥的选择（防御起点）
密钥分两类：
- **DK（Data Key，数据加密密钥）**：直接对数据加密
- **KK（Key Key，密钥加密密钥）**：保护密钥本身的安全传递

密钥生成 3 要素：
| 因素 | 要点 |
|------|------|
| 增大密钥空间 | 加长密钥位数（位数越长破解时间指数级增长，具体依赖攻击方算力） |
| 选择强钥 | 避免简单易记的密钥（弱钥易被字典攻击） |
| 保证随机性 | 需满足**均匀分布**（每数出现频率相等）+ **独立性**（不能由其他数推出）+ **不可预测性** |

### 2. DoS 与 DDoS

#### DoS（Denial of Service，拒绝服务攻击）
使系统不可访问，拒绝合法用户的服务请求。两种攻击思路：
1. 让服务器缓冲区满，不接收新请求
2. 使用 IP 欺骗，迫使服务器把合法用户的连接复位

**传统 DoS 的 4 种攻击模式**：消耗资源 / 破坏或更改配置 / 物理破坏网络部件 / 利用服务程序处理错误。

#### DDoS（Distributed DoS，分布式拒绝服务攻击）
攻击者先侵入多台计算机，控制它们**同时**向目标发起攻击。

**三级结构**：
```
Client（攻击者主机）→ Handler（主控端）→ Agent（代理端/肉鸡）→ 目标
```
- **Client**：攻击者发起和控制
- **Handler**：被入侵的主机，控制代理端
- **Agent**：被入侵的主机，执行实际攻击

**DDoS 克服了传统 DoS 的两个致命弱点**：网络资源限制（单机攻击力有限）和隐蔽性差（容易被追踪）。

#### 被攻击时的 6 种现象
大量等待 TCP 连接 / 大量非服务连接数据分组 / 网络充斥无用数据包（源地址为假）/ 高流量造成拥塞 / 反复发出服务请求 / 严重时死机。

#### 防御方法（4 种）
加强数据包特征识别 / 防火墙监视敏感端口 / 对通信数据量统计（攻击前域名查询量异常增加）/ 及时修正已发现的漏洞。

### 3. 欺骗攻击 3 类（高频考点）
| 攻击 | 伪造什么 | 是否需先瘫痪目标 |
|------|---------|----------------|
| ARP 欺骗 | MAC 地址（IP→MAC 映射） | 需让被冒充的主机瘫痪 |
| DNS 欺骗 | DNS 解析结果（域名→IP） | **不需要** |
| IP 欺骗 | 源 IP 地址 | 需让被冒充的发送方瘫痪 |

#### ARP 欺骗
- **ARP（Address Resolution Protocol，地址解析协议）**：把 IP 映射为 MAC 地址
- 原理：攻击者让被冒充主机瘫痪，再伪造 ARP 应答，使受害者的 ARP 缓存把目标 IP 对应到攻击者的 MAC，数据实际发给攻击者
- 类比：偷偷改了通讯录里朋友的地址改成自己的，快递就寄到攻击者手里
- 防范：固化 ARP 表（`arp -s`）/ ARP 服务器 / 双向绑定 / ARP 防护软件

#### DNS 欺骗
- 原理：冒充 DNS 服务器，把域名对应 IP 改成攻击者 IP，用户访问网站实际访问攻击者服务器
- **不需要瘫痪目标主机**，只需抢在真 DNS 服务器前回复伪造解析
- 检测 3 种方法：
  | 方法 | 原理 |
  |------|------|
  | 被动监听检测 | 一个请求对应多个不同应答则可疑 |
  | 虚假报文探测 | 向非 DNS 服务器发请求，收到应答说明有攻击者 |
  | 交叉检查查询 | 收到应答后反向查 IP 对应域名，不一致则被欺骗 |

#### IP 欺骗
- 原理：伪造数据包源 IP；**必须先让被冒充主机瘫痪**（DoS），否则真正主机会发 RST 重置连接
- 防范：删除信任主机文件 / 防火墙过滤"来自外部但源地址是内部 IP"的报文

### 4. 端口扫描（攻击者的侦察手段）
端口用 **[IP:端口]** 定位主机中的进程（类比：计算机是大楼，端口是入口，不同入口里是不同进程）。

**目的**：判断目标开放了哪些服务 / 判断目标操作系统类型。

**4 种扫描方式（隐蔽性递增）**：
| 方式 | 原理 | 隐蔽性 |
|------|------|-------|
| 全 TCP 连接 | 完成三次握手 | 低（容易被记录） |
| 半打开式（SYN 扫描） | 发 SYN，收到 SYN+ACK 后发 RST 中断 | 较高（连接未建立） |
| FIN 扫描 | 发 FIN=1，关闭端口返回 RST，开放端口无回应 | 高（不建立连接） |
| 第三方扫描（代理扫描） | 利用被入侵的"肉鸡"代替扫描 | 最高（目标只能追溯到肉鸡） |

> 端口扫描本身是**攻击者的侦察手段（踩点）**，不是防御。防御者的利用点：扫描时入侵者要往端口发大量请求最容易暴露，可监控异常端口访问发现入侵。真正的防御是漏洞扫描（4.7.6）——自己先扫自己，赶在攻击者前修补。

### 5. 强化 TCP/IP 堆栈抵御 DoS

#### SYN Flooding（同步包风暴）⭐ 最流行的 DoS/DDoS 方式
- 原理：利用 TCP 三次握手——攻击者大量发 SYN 包但不完成第三次握手，服务器维护大量半连接耗尽资源
- 攻击者伪造不可达 IP 作源地址，服务器发出的 SYN+ACK 永远收不到回应
- 防御：修改注册表键值（如 SynAttackProtect、TcpMaxHalfOpen 等）

#### ICMP 攻击
利用 ICMP 协议攻击。如 **Ping of Death**：发送超过 64KB 的 ICMP 数据包导致 TCP/IP 堆栈崩溃。

#### SNMP 攻击
SNMP（Simple Network Management Protocol，简单网络管理协议）用于管理网络设备。攻击者可利用它控制设备、重定向通信甚至断开连接。

### 6. 系统漏洞扫描（防御手段）
| 类型 | 原理 | 特点 |
|------|------|------|
| 基于网络的扫描 | 远程扫描，不需要在目标装东西 | 便宜、不需目标配合、维护简便 |
| 基于主机的扫描 | 在目标系统上安装代理（Agent） | 扫描漏洞数量更多、集中化管理、网络流量负载小 |

> 类比：基于网络像在外面看大楼有几个门开着；基于主机像在大楼内部每个房间检查。

### 7. 被动攻击 vs 主动攻击（概念区分）
> ⚠️ 教材外补充：通行安全概念（4.7 材料未展开），作理解辅助。
- **被动攻击**：流量分析、窃听——只观察不修改，难发现但可防（加密）
- **主动攻击**：DoS、欺骗、篡改、重放——修改或伪造，可发现但难完全防

## 二、顾问指引（真实项目 AI 怎么用）

1. **密钥强度**：建议至少 16 字节以上随机密钥，避免弱钥（字典攻击）；密钥生成用密码学安全的随机数源，不用普通伪随机。
2. **防 DDoS**：不能只靠单机防御。基础措施——数据包特征识别 + 防火墙端口监视 + 流量基线统计 + 及时补漏洞；大规模需 CDN/清洗服务。
3. **防欺骗**：ARP 欺骗在局域网内做绑定；DNS 启用 DNSSEC 或可信 DNS；IP 欺骗靠防火墙过滤"外部来的内部源 IP"。
4. **端口暴露面收敛**：只开放必要端口，关闭调试/管理接口的外网访问；定期自己扫自己（漏洞扫描）赶在攻击者前发现。
5. **SYN Flooding 防护**：调内核参数（SYN cookies、半连接上限）；高并发服务前端加负载均衡/防护设备。

## 三、常见误区（AI 自检红线，来自真实学习错题）

- ❌ **三种欺骗攻击"都需先瘫痪目标"** → DNS 欺骗不需要瘫痪目标主机，只需抢答伪造解析；ARP 和 IP 欺骗才需要先让被冒充方瘫痪。
- ❌ **端口扫描当防御手段** → 端口扫描是攻击者的侦察（踩点）。防御者的对应手段是**漏洞扫描**（自己先扫自己）。
- ❌ **DDoS 只当"DoS 的加强版"** → 关键是突破了 DoS 的两个弱点：资源限制（多机合力）和隐蔽性（间接攻击难追踪）。
- ❌ **FIN 扫描当"建立连接的方式"** → FIN 扫描根本不建立连接（发 FIN 看回应），所以隐蔽性高。
- ❌ **把"被攻击现象"和"攻击模式"混为一谈** → 6 种现象是受害侧观察到的征兆；4 种攻击模式是攻击者的手段分类。
