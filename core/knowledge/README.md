## 三层索引机制

- **L1 本文件**：按章分组 + 主题关键词导航。AI 先读，定位"问题属于哪个组"
- **L2 按章分组**（`NN-章名/` 子目录）：组内 2-6 文件，一眼定位
- **L3 知识文件**：四层结构（核心知识 + 顾问指引 + 误区红线 + 自检清单）

**AI 索引路径**：用户问"ATAM" → 读 L1 → 定位 `08-质量评估/` → 读"架构评估方法.md"。两次跳转，精准定位。
