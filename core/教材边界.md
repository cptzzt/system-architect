# 教材边界 — 有/无教材各能做什么

> 这是 AI 必读的核心规则文件。决定 AI 在"有教材"和"无教材"两种状态下的能力边界和行为差异。

## 为什么有这个边界

本 skill **不含教材原文**（版权属于出版社）。内置知识层（core/knowledge）是重组知识，可独立工作；用户教材是可选的"权威溯源源"。AI 必须明确区分两种状态，不能假装有教材、也不能在有教材时浪费溯源能力。

## 无教材（默认状态）

**能做**：
- 基于内置知识层（core/knowledge）讲解架构知识
- 给架构建议、做表设计、技术选型对比
- 用工程经验补充知识层未覆盖的内容

**必须做**：
- 涉及"工程经验/业界实践"而非知识层结论时，**显式标注**："⚠️ 工程经验，非权威依据，需结合项目判断"
- 不假装引用教材出处
- 涉及精确考点/判卷时，提示用户"建议以权威教材核实"

**不能做**：
- 编造教材原文/页码
- 把工程经验说成"教材这么写的"

## 有教材（用户填了路径或口头告知）

**教材格式**：推荐 Markdown（便于按页码/章节溯源）。PDF/图片推荐先用 [MinerU](https://mineru.net/) 转 md（按页码分段、带搜索）。

**能做**（比无教材更强的能力）：
- 需溯源时 Read 教材对应章节，给建议标注出处（"教材第 X 章 / 第 N 页指出…"）
- 判卷/纠错以教材原文为**唯一标准**，不凭 AI 自身知识
- 做考点对齐、精确概念辨析、论文/案例题评分

**必须做**：
- 每次需溯源时，**先探测教材路径是否有效**（用户上下文里的路径 / textbook/ 目录 / 口头告知）
- 引用教材时标文件名 + 章节/页码
- 判卷时若 AI 印象与教材冲突，以教材为准（不拿领域知识纠正教材原文）

**降级机制**：
- 教材路径无效/对应章节没找到 → 降级到"无教材"状态处理，并告知用户"未找到教材，以下基于内置知识层"

## 不确定性标注规范

| 来源 | 标注方式 |
|------|---------|
| 内置知识层结论 | "按知识体系，应…"（可直接给） |
| 教材支撑（有教材时） | "教材第 X 章指出…" |
| 工程经验（无权威背书） | "⚠️ 工程经验，非权威依据" |
| 不确定 | 直接说"不确定"，不硬答 |

## 教材探测时机

- 用户问"教材怎么说"/"考点"/"判卷" → 必须探测教材
- 用户问真实项目设计 → 可不探测（工程经验为主）
- 混合场景 → 先探测，在则溯源，不在则降级
