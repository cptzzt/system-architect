# System Architect — 让 AI 成为系统架构设计师

> 版本：v0.3（综合知识 2-11 章已校验；案例 12-19 + 论文 20 待补）
> 协议：MIT

一个 Claude Code skill：让 AI 基于权威架构知识体系**成为系统架构设计师**——建议可溯源、不凭空生成。可用于真实项目架构设计辅助，也可用于备考「系统架构设计师」。

## 快速开始

1. **装 skill**：克隆本仓库到 Claude Code 的 skills 目录
2. **（可选）接教材**：教材电子版放 `textbook/`（推荐 Markdown，可用 [MinerU](https://mineru.net/) 转），或改 `SKILL.md` 里的教材路径
3. **填上下文**：编辑 `SKILL.md` 顶部"用户上下文"段（你的技术栈/方向/是否备考）
4. **开用**：问架构问题（自动套用**架构顾问模式**）；或说"我要备考系统架构设计师"（套用**学习导师模式**）

> 无教材也能用——`core/knowledge/` 内置知识层可独立工作。接入教材后，建议可溯源到教材原文。

## 在其他 AI 工具使用

本 skill 用 Claude Code 的 `SKILL.md` 格式，但**知识层（`core/knowledge/`）工具无关**——都是纯 Markdown 知识，任何 AI 编码工具都能用。

**其他工具适配**（使用者自行操作）：

1. **知识层原样保留**：`core/knowledge/` 不用改
2. **把 `SKILL.md` 指令复制到你的工具规则文件**：

   | 工具 | 规则文件 |
   |------|---------|
   | Cursor | `.cursorrules` 或 `.mdc`（用 `@路径` 引用知识文件） |
   | Windsurf | `.windsurfrules` |
   | Cline | `.clinerules` |
   | GitHub Copilot | `.github/copilot-instructions.md` |
   | 通用跨工具 | `AGENTS.md` |

3. **调整子文件引用语法**：`SKILL.md` 用 Markdown 链接路由，各工具语法略不同（如 Cursor 用 `@core/knowledge/...`），按你的工具改。

> 各工具规则格式会随版本更新，以你工具的官方文档为准。本 skill 只维护 Claude Code 版，其他工具由使用者适配（知识层零改动）。

## 这个 skill 是什么

**主体 = 让 AI 成为系统架构设计师**。它造了一个"架构师 AI"：
- 能**独立**辅助真实项目架构设计（无教材也能用）
- 备考用户可选"学习导师模式"——学完教材 = AI 自然"懂"架构（学习→顾问延续）

## 核心设计

| 部分 | 作用 |
|------|------|
| **主体**（SKILL.md + core/） | 架构师内核 + 内置知识层。AI 的"自身能力" |
| **教材边界**（core/教材边界.md） | 有/无教材各能做什么，明确声明 |
| **模式**（modes/） | 可选子项：架构顾问（默认）、学习导师（备考）、技术选型 |

- **progressive disclosure**：SKILL.md 精简路由（<500 行），知识按主题按需加载
- **具体到个人**：SKILL.md 顶部"用户上下文"段，用户改自己的技术栈/方向

## 差异化

| 竞品 | 缺口 |
|------|------|
| 软考 GitHub 项目（题库类） | 静态资料库，无 AI/无方法/无溯源 |
| AI 架构助手（Copilot/ChatGPT） | 基于自身知识，无 grounding/无溯源/可能过时 |
| Claude 架构 skill（MCP Market 等） | 英文 Clean/DDD，非中文软考体系 |
| **本 skill** | 权威知识 grounding + 可溯源 + AI 互动 + 学习→顾问延续 + **无教材也能用** |
